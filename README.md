# BillClick Website

Public website for **BillClick**, the company and services layer connected to the VaadBot and VaadBit residential-building management ecosystem.

## Purpose

The website presents BillClick's digital services, products, and public business positioning for the Israeli market.

Product ecosystem:

- **VaadBot**: building/property-management application.
- **VaadBit**: financial and operational workflows for shared residential buildings.
- **BillClick**: public business/service layer around the product ecosystem.

## Technology

- SvelteKit
- TypeScript
- Static adapter
- Vite
- CSS
- GitHub Actions deployment

## Development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Content Notes

This is a public-facing website. Keep copy clear, professional, and customer-oriented. Do not expose private repositories, infrastructure, internal IPs, credentials, or customer data.

## Security

Do not commit analytics secrets, tokens, API keys, or private operational data.
